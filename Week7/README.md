# Week 7 — Abstraction and Interfaces

Solutions for the five Category B Assignment problems and five Category B Practice problems from the uploaded Week 7 PDFs.

Each Java file is self-contained, uses nested classes/interfaces to keep it compilable as one source file, and includes a main method demonstrating the required behavior.

Compile/run example from repository root:

```bash
javac Week7/Assignment/Problem1_MorningWakeUpCircuit.java
java -cp Week7/Assignment Problem1_MorningWakeUpCircuit
```

Repeat with the desired filename and public class. Java 8+ recommended. The code demonstrates interfaces, abstract classes, multilevel and hierarchical inheritance, overriding, overloading, and runtime polymorphism.
