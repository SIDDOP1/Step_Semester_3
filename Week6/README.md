# Week 6 — Inheritance & Polymorphism

Solutions are organized by the two uploaded PDFs:
- `Assignment/`: Gym Membership Foundation & Batch Trial Sign-up; Three Tiers of Gym Membership; Premium Loyalty Discount & Late-Fee Ledger; Monthly Attendance Announcer; Membership Numbers, Referral Codes & Weekly Check-in Settlement.
- `Practice/`: Library Membership Foundation & Batch Enrollment; Three Branches of the Membership Tree; Student Discount & Fine Ledger; Weekly Circulation Report; Membership Numbers, Renewal Codes & Nightly Circulation Audit.

Each problem is a self-contained Java source file with one public class matching its filename. Compile/run example:

```bash
javac Week6/Assignment/Problem1_GymMembershipFoundation.java
java -cp Week6/Assignment Problem1_GymMembershipFoundation
```

Use Java 11 or newer. Some PDFs describe member-number display as a formatted ID while also showing a numeric field; getters expose the numeric sequence and the source examples are demonstrated in each main method where practical.
