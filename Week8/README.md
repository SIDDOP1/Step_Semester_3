# Week 8 — Object Modeling & Workflows

Solutions for both Week 8 PDFs:
- Assignment: Hostel Laundry Queue; Assignment Submission Portal; Campus Premiere Ticket Counter; FitZone Membership Desk; Campus Notice Broadcaster.
- Practice coding: Vehicle Rental System; Employee Leave Request Workflow; Online Examination System; Hotel Booking System; Payment Processing for a Shopping System.
- Practice theory: Quiz_and_Concept_Answers.md contains all 10 multiple-choice answers and all 5 concept responses.

Each coding problem is a standalone Java file with a matching public class. Compile/run example:

```bash
javac Week8/Assignment/Problem1_HostelLaundryQueue.java
java -cp Week8/Assignment Problem1_HostelLaundryQueue
```

Use Java 11 or newer. Dates use java.time. The practice PDF uses placeholders $X/$Y rather than specifying rental/room prices; illustrative daily rates are used in those examples. Cancellation deadlines and leave-policy thresholds are configurable by the caller.
