## Run
Each file is a self-contained Java program with a public class matching its filename. From the repository root, for example:

```bash
javac Week9/Assignment/Problem1_ClassTopperFinder.java
java -cp Week9/Assignment Problem1_ClassTopperFinder
```

Use Java 8 or newer. The source PDFs express function signatures in Python-style notation; this repository's prior weekly solutions are Java, so equivalent Java methods and array-based inputs are provided. Where a PDF requests a tuple, the Java method returns an array and the main method prints the equivalent tuple representation.
